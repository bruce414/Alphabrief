# v0 Landing Page Reference

These files are design references generated from v0 by Vercel.

They may include Next.js-specific code and should not be copied directly into the Vite frontend without conversion.

Use this style direction for Alphabrief:
- Minimal
- Clean
- Professional
- Finance/SaaS-oriented
- Soft borders
- Rounded cards
- Muted text
- Subtle gradients
- Strong but restrained hierarchy

Avoid:
- Fake traction claims
- Overly colorful visuals
- Crypto-style hype
- Unverified accuracy claims
